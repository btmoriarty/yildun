# Drift Registry

Questions this world has deliberately not answered.

## The closure rule

**Any run may open a drift. No run may close one. Only the author, in writing, dated.**

This includes closing by inference. Writing prose that only makes sense if a drift were resolved
resolves it, whatever the notes say. If an entry touches a held question, its provenance note must
say which one and how it avoided settling it.

**A drift is not a to-do item.** The world is built out of them. Opening one is free and costs
nothing; closing one spends depth for content and cannot be undone.

## How to write one

| Field | What goes in it |
|---|---|
| **Question** | Stated as a question, not as a mystery. What specifically is unresolved. |
| **Status** | `held` by default. `closed` only with an author quote and a date. |
| **Readings** | The live possibilities, **unranked**. If one is obviously right, this is not a drift. |
| **Guard** | What a later run might do that would accidentally resolve it. Write this. It is the field that actually works. |
| **Touched by** | Entries that engage it without settling it. |

## The two kinds worth having

**Author-declared.** The author says a thing is not to be settled. These are the strongest and
they usually come out of the interrogation's unresolved pass, where a real question from a real
life becomes a permanent feature of the fiction.

**Structural.** Two entries the world could collapse into one, and is better for not collapsing.
Resist the collapse; the tension is the value.

## Guard against the commonest failure

**A new instance of a pattern deepens it. It never concludes it.** When a third example of
something arrives and the shape finally looks clear, that is precisely when a run will write the
sentence that turns evidence into a finding. Do not. Add the instance and leave the pattern open.
